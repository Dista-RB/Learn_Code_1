## 1. Question

- ถ้าเขียนโปรแกรมคำนวณ GPA ด้วย Python และ C++ ผลลัพธ์จะตรงกันไหม

ทำไมสำคัญ: เดือนถัดไปต้องใช้ทั้ง Python และ C++ คู่กัน (เช่น `algo-bench` ใน M4 เขียน C++ แล้ว plot ด้วย Python)

## 2. Method

สูตรที่ใช้:

```
GPA = Σ (grade point × credit) / Σ credit
```

ตารางแปลงเกรด (ระบบ 4.00):

| Grade | A | B+ | B | C+ | C | D+ | D | F |
|---|---|---|---|---|---|---|---|---|
| Point | 4.00 | 3.50 | 3.00 | 2.50 | 2.00 | 1.50 | 1.00 | 0.00 |

ทั้งสองไฟล์แบ่งงานเป็นฟังก์ชันชื่อเดียวกัน:

1. `EnterName()` รับจำนวนวิชา แล้วรับชื่อวิชา หน่วยกิต และเกรดของแต่ละวิชา ถ้ากรอกผิดจะถามใหม่
2. `GradeToPoint()` แปลงเกรดตัวอักษรเป็นแต้ม (เกรดที่ไม่มีในตารางได้ `-1` เพื่อบอกว่าผิด)
3. `CalculateGPA()` คำนวณเกรดเฉลี่ยถ่วงน้ำหนัก
4. แสดงตารางวิชาและ GPA ทศนิยม 2 ตำแหน่ง (Python ใช้ `DisplayResult()`, C++ พิมพ์ใน `main()`)

**Baseline:** คิดเลขด้วยมือ แล้วเทียบกับผลของทั้งสองภาษา

## 4. Results

ข้อมูลตัวอย่าง:

| วิชา | หน่วยกิต | เกรด |

| Calculus 1 | 3 | A |
| Physics 1 | 3 | B+ |

| วิธี | GPA |
|---|---|

ผลลัพธ์ที่ทั้งสองภาษาแสดง (เหมือนกันทุกตัวอักษร):

```

```

โปรแกรมไม่มีการสุ่ม รันกี่ครั้งก็ได้ค่าเดิม จึงไม่ต้องรายงาน mean ± std

ทดสอบการกรอกผิด:

| กรณี | Python | C++ |
|---|---|---|
| จำนวนวิชาเป็น 0 หรือไม่ใช่ตัวเลข | ถามใหม่ | ถามใหม่ |
| หน่วยกิตเป็น 0 หรือติดลบ | ถามใหม่ | ถามใหม่ |

| เกรดตัวพิมพ์เล็ก (เช่น `b+`) | รับได้ (แปลงเป็นตัวใหญ่ให้) | ไม่รับ ต้องพิมพ์ตัวใหญ่ |

## 5. Discussion & limitations

ทั้งสองภาษาให้ GPA ตรงกับที่คิดด้วยมือ และจัดตารางออกมาเหมือนกัน
ส่วนที่ต่างกันคือวิธีเขียน:

- Python เก็บตารางเกรดใน dictionary ส่วน C++ ใช้ `if` ทีละเกรด
- Python ตรวจตัวเลขผิดด้วย `try/except ValueError` ส่วน C++ ใช้ `cin.fail()`, `cin.clear()`, `cin.ignore()`
- Python ใช้ `.upper()` จึงรับเกรดตัวเล็กได้ แต่ C++ เทียบข้อความตรงๆ

ข้อจำกัด:

- C++ รับเกรดได้เฉพาะตัวพิมพ์ใหญ่
- ถ้าส่ง input จากไฟล์แล้วข้อมูลหมดก่อนกรอกครบ ฝั่ง C++ จะวนไม่จบ ส่วน Python จะหยุดพร้อม `EOFError`
- ชื่อวิชาที่ยาวเกิน 20 ตัวอักษรจะทำให้ตารางเบี้ยว
- ตัวแปร `value` คือหน่วยกิต และ `gpa` คือเกรดตัวอักษร ชื่อไม่ตรงความหมายจึงอ่านโค้ดแล้วสับสนได้
- ยังไม่มี automated test และ CI

## 6. Reproduce

รันแบบกรอกเอง:

```bash
python test.py
```

```bash
g++ -std=c++17 -O2 test.cpp -o gpa && ./gpa
```

รันด้วยข้อมูลตัวอย่างในคำสั่งเดียว (Git Bash / Linux / macOS) ควรได้ `Your GPA = 3.31`:

```bash
printf '3\nCalculus 1\n3\nA\nPhysics 1\n3\nB+\nEnglish\n2\nC\n' | python test.py
```

```bash
g++ -std=c++17 -O2 test.cpp -o gpa && printf '3\nCalculus 1\n3\nA\nPhysics 1\n3\nB+\nEnglish\n2\nC\n' | ./gpa
```
